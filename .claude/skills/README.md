# .claude/skills — 自動生成

下に挙げたスキルは中央リポジトリ ai-workflows の `plugins/*/skills/*/` から
`sync-skills.sh` が配置している。**手で編集しない** (次回の同期で上書きされる)。
ここに挙がっていないスキルは、このリポジトリ自身のもの。

規約を変えるときは中央リポジトリを直し、各リポジトリで同期を流し直す:

```bash
/path/to/ai-workflows/scripts/sync-skills.sh
```

配置されているスキル:

- artifact-writing
- dev-loop
- git-conventions
- issue-design
- issue-implement
- output-contract
- pr-fix
- pr-review
